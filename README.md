# worst-fix-commit-message

A one-line commit message for a bug fix that made things worse. Four thousand cron emails stop going to Steve and go to his emergency contact instead, who is his dentist.

## Run it

```bash
python3 main.py
```

That writes the line to `/output/entry.txt`.
